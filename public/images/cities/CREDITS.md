# Fotografías de ciudades

Fotografías de referencia de lugares reales, no de las propiedades ficticias del catálogo.
Archivos originales descargados de Wikimedia Commons y conservados sin modificación.
La aplicación utiliza derivados WebP redimensionados y comprimidos a calidad 76, bajo las mismas licencias de sus originales; el encuadre se adapta mediante CSS.
Se regeneran con el script npm images:optimize (Sharp, solo desarrollo). La variante «800» de La Serena conserva sus 497 px originales, sin ampliación.
